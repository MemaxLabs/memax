## User Feedback Compilation -- March/April 2026

Aggregated from Discord (#feedback channel, 47 messages), support emails (12 tickets), and in-app feedback widget (23 submissions). Total: 82 feedback items from 58 unique users.

### Theme 1: Recall Quality (28 mentions)

- "Sometimes I push something and can't find it 5 minutes later" -- 9 users
- Short queries (1-2 words) return irrelevant results -- 7 users
- Recall works well for recent memories but misses older content -- 6 users
- Users want to know WHY a memory was returned (relevance explanation) -- 6 users

**Status:** Hybrid search (shipped March 28) addressed short query issues. Relevance explanation is on the Q3 roadmap under "Ask bar redesign."

### Theme 2: Push Friction (19 mentions)

- "I forget to push because it's not automatic" -- 8 users
- CLI push is fast, but web push requires too many clicks -- 6 users
- Users want to push from inside their editor, not switch to terminal -- 5 users

**Status:** Auto-capture from agent sessions (Q3 P0) will address the automation gap. Web push UX will be simplified in the Ask bar redesign.

### Theme 3: Hub Organization (16 mentions)

- "My personal hub is a mess after 200 memories" -- 7 users
- Want folders or tags for manual organization -- 5 users
- Want to move memories between hubs -- 4 users

**Status:** Topics and clustering (Q3 P1) will auto-organize memories. Hub-to-hub memory transfer is not yet planned.

### Theme 4: Team Features (12 mentions)

- "I can't tell which of my memories are actually useful to the team" -- 5 users
- Want @mentions or targeted push to specific teammates -- 4 users
- Want approval workflow before memories appear in shared hub -- 3 users

**Status:** Team hub analytics (Q3 P0) addresses visibility. Targeted push and approval workflows are Q4 considerations.

### Theme 5: Misc (7 mentions)

- API rate limits too aggressive for CI/CD pipelines -- 3 users
- Want dark mode in web app (already shipped, users not finding the toggle) -- 2 users
- Export/backup of all memories -- 2 users

## User Interview Summary -- March 2026 Batch

Conducted 3 interviews with beta users during the week of March 18-22, 2026. Interviews lasted 30-45 minutes each over Zoom.

### Interview 1: Marcus (Senior SWE, fintech startup, 12-person team)

- Uses Claude Code daily, pushes ~8 memories/day
- Pain point: "I push things but never know if my teammates benefit from them"
- Wants: visibility into how often his shared memories get recalled by others
- Would pay $9/mo for personal use, $15/seat for team (below our $19 target)
- Quote: "If I could see that my debugging notes saved someone else 2 hours, I'd push way more"

### Interview 2: Priya (Tech Lead, e-commerce, 40-person eng org)

- Evaluated Mem0 but rejected it because no team features
- Currently uses Notion + manual copy-paste into Claude context
- Wants: automatic capture from agent sessions, not just manual push
- Would pay $19/seat if it replaces their internal wiki for agent context
- Quote: "We have 200 pages of runbooks that nobody reads. If the agent could just know them, that's worth $19 easy"

### Interview 3: Alex (Solo indie hacker, 1-person company)

- Uses Cursor + ChatGPT, switches between projects frequently
- Pain point: re-explaining project context every new session
- Wants: project-scoped recall that auto-loads relevant memories
- Would not pay -- expects free tier to cover solo use
- Quote: "I'd use the free tier forever unless you make me pay for project switching"

### Key Findings

1. **Team visibility is the #1 unlock for paid conversion** -- users want to see impact of shared memories
2. **Auto-capture is table stakes for non-CLI users** -- manual push friction is real
3. **Solo users will not pay unless we gate something they already depend on** -- free tier must have a ceiling

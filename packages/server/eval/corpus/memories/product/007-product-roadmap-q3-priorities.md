## Product Roadmap: Q3 2026 Priorities

Finalized in product review on April 8, 2026. Priorities ranked by weighted scoring (impact x confidence x urgency).

### P0 -- Must Ship

1. **Ask bar redesign** (April 28) -- Unified recall/capture modal with streaming results. Blocks activation metric improvement. Owner: Sarah/Ziyang.
2. **Auto-capture from agent sessions** (May 15) -- Extract and push memories from Claude Code and Cursor session artifacts automatically. #1 user request from interviews. Owner: Jiahao.
3. **Team hub analytics** (May 30) -- Dashboard showing push/recall activity per member, most-accessed memories, knowledge gaps. Unlocks team tier conversion. Owner: Sarah.

### P1 -- Should Ship

4. **Onboarding checklist and seeded memories** (May 10) -- Interactive first-run experience with 3 example memories and guided recall. Target: reduce signup-to-first-push drop-off by 15pp. Owner: Sarah.
5. **SSO/SAML support** (June 15) -- Required for NovaTech pilot and Acme Corp deal. Auth0 integration. Owner: Ziyang.
6. **Memory topics and clustering** (June 30) -- Auto-organize memories into topics using LLM classification. Powers the "knowledge map" view. Owner: Jiahao.

### P2 -- Nice to Have

7. **Mobile web optimization** (July) -- Responsive Ask bar and hub views for 375px+ screens.
8. **Zapier/Make integration** (July) -- Push memories from external tools via webhook.
9. **Memory expiration policies** (August) -- Auto-archive volatile memories after configurable TTL.

### Deferred to Q4

- Self-hosted deployment option
- Advanced permissions (field-level access control)
- Multi-language support (i18n for non-English content)

### Success Criteria for Q3

- D7 retention: 30% -> 45%
- Recall usage per session: 0.3x -> 2.0x
- Team tier conversion: 8% -> 15% of paid users
- At least 1 enterprise pilot signed ($5K+ MRR)

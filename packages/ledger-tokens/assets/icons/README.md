# Icons

The lifecycle state marks as 16px single-ink SVGs, in Paper's tokens, for email, docs and anywhere outside React. In the product, use StateMark, which follows the theme. Kept memories carry no mark in lists; `state-kept.svg` is for labels and legends.

- `state-proposed.svg`: a ring, `ochre` `#895909`.
- `state-kept.svg`: a disc, `seal` `#1b5a3e`.
- `state-merged.svg`: two linked rings, `ink-3` `#5c625f`.
- `state-stale.svg`: a dashed ring, `ink-3`.
- `state-faded.svg`: a soft disc, `ink-3` at 38% opacity.
- `state-conflict.svg`: a half disc, `vermilion` `#b23521`.
- `state-forgotten.svg`: a redaction bar, `ink` `#151b18`.

UI icons are the line set in the `Icon` component: a 24px grid, 1.5px stroke, round caps, `currentColor`.
